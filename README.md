# Liman Rapor Sistemi (Port Report System)

Bu proje, liman operasyonlarını takip etmek ve raporlamak için geliştirilmiş modern bir web arayüzüdür.

## Özellikler

- **Responsive Tasarım**: Masaüstü ve mobil cihazlarda mükemmel görünüm
- **Gemi Takibi**: Limana gelen gemilerin gerçek zamanlı takibi
- **Rapor Yönetimi**: Gemi giriş ve yük boşaltma raporları
- **İstatistikler**: Günlük ve aylık performans metrikleri
- **Arama Özelliği**: Gemiler arasında hızlı arama
- **Gerçek Zamanlı Güncellemeler**: Otomatik veri güncelleme

## Teknolojiler

- HTML5 & CSS3
- Vanilla JavaScript
- Font Awesome Icons
- Responsive Grid Layout

## Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/mehmetcelikkol/web-limanrapor.git
cd web-limanrapor
```

2. Local server başlatın:
```bash
python3 -m http.server 8000
```

3. Tarayıcınızda açın:
```
http://localhost:8000
```

## Kullanım

### Ana Sayfa
- Günlük operasyon istatistiklerini görüntüleyin
- Sistem durumunu takip edin

### Raporlar
- **Gemi Giriş Raporu**: Yeni gemi gelişlerini kaydedin
- **Yük Boşaltma Raporu**: Kargo operasyonlarını dokumentasyonlayın

### Gemiler
- Mevcut gemileri ve durumlarını görüntüleyin
- Gemi arama özelliğini kullanın

### İstatistikler
- Günlük operasyon grafiklerini inceleyin
- Aylık performans metriklerini takip edin
